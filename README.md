# 靡靡之音 · MIDI.CN

全屏沉浸式 3D 音乐游戏首页。深海绿、幽紫与珍珠光，实时着色器生命体、音波轨道、音符、粒子与波浪声场。首页仅展示现有游戏「吞噬交响曲」，移除此前两个演示游戏。

运行 npm start，访问 http://127.0.0.1:4190 。npm run check 检查脚本。

点击「开启声音」或「先听听，这个宇宙」开启 Web Audio 原创环境音乐。使用真实频谱分析驱动生命体与音波环。点击场景或交互提示可以旋转生命体。支持全屏、移动端、减少动态效果偏好与 WebGL 不可用时的后备视觉。

无后端、无安装依赖。Three.js 与许可位于 dist/symphony/vendor。Google Fonts 为可选字体，断网使用系统中文字体。游戏为同工作区原项目的独立快照，原项目不受修改影响。域名 midi.cn 尚未绑定。
