# 迷音游戏 · MIDI.CN

音乐游戏门户首页。奶油白、珊瑚橙与鼠尾草绿，实时 Three.js 音乐装置，支持拖动旋转。

运行 `npm start`，访问 http://127.0.0.1:4190 。执行 `npm run check` 检查脚本。

游戏包括：吞噬交响曲（从同工作区原项目复制的独立快照）、节拍弹跳（16 拍挑战）、口袋合成器（Web Audio 七音演奏）。首页迷你琴支持 A S D F G H J。声音须先交互开启。

无后端、无安装依赖。Three.js 与许可保留于 dist/symphony/vendor。Google Fonts 可选加载；网络不可用时使用本地中文字体。支持手机与减少动态效果偏好。页面中的环境声、音色、节拍均实时合成。

部署产物为 dist/。域名 midi.cn 需要在正式上线时单独配置 DNS；本项目不会更改现有域名设置。
